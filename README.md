# Sistema Archaios
Proyecto de la asignatura Acceso a Datos del ciclo superior de Desarrollo de Aplicaciones Multiplataforma(DAM) Perteneciente al grupo LosdeAtras.
Simula un sistema de arqueología.

## Dependencias
El sistema necesita las librerías:

-Gson v2.14.0 o superior.<br>
-Terra v1.x.x o superior.

## Museo
El sistema está conformado por dos partes, el cliente, presente en este repositorio, y el servidor, localizado en el repositorio Archaios_Museo.

Los diversos programas Archaios se conectarán a un único Museo localizado en un servidor web XAMP.
